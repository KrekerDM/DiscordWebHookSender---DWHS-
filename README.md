# Discord Webhook Sender

Полнофункциональный десктоп-генератор сообщений для Discord-вебхуков. Интерфейс приложения — в стиле Material Design 3 (шрифт Inter, пронумерованная навигация 1–4, скруглённые filled-поля), а панель предпросмотра сообщения — пиксельно точная копия того, как оно будет выглядеть в самом Discord. Написан на Python + PySide6 (Qt).

Сделано [KrekerDM](https://github.com/KrekerDM).

## Возможности

- Управление несколькими вебхуками: добавление, переименование, дублирование, удаление, быстрое переключение через боковую панель.
- Полный редактор сообщения: текст (2000 символов с счётчиком), имя бота и аватар (переопределение), TTS, имя ветки для форум-каналов.
- Редактор embeds (до 10 на сообщение): автор, заголовок со ссылкой, описание, цвет полосы (палитра + свой HEX + случайный), миниатюра, изображение, подвал с меткой времени, поля (inline/full-width, перестановка, дублирование).
- Живой предпросмотр, пиксельно приближённый к настоящему Discord: аватар, бейдж BOT, markdown (жирный/курсив/зачёркнутый/код/спойлер/цитаты/ссылки), карточки embed с реальной загрузкой изображений по URL.
- Вложения файлов (до 10 файлов, до 25 МБ каждый) через multipart-отправку.
- JSON-редактор: импорт готового payload вставкой JSON и экспорт текущего сообщения одной кнопкой.
- Шаблоны сообщений — сохранение и загрузка целых заготовок (текст + embeds) в отдельном менеджере.
- История отправленных сообщений на вебхук с возможностью редактировать (PATCH) и удалять (DELETE) уже отправленные сообщения.
- Проверка соединения с вебхуком (GET) прямо из интерфейса.
- Все сетевые запросы выполняются в фоновом потоке — интерфейс не подвисает.
- Все данные (вебхуки, история, шаблоны) хранятся только локально в папке `data/`.

## Локализация

Интерфейс переведён на русский, English и українську — переключатель языка находится внизу боковой панели. Смена языка сохраняется сразу, но применяется после перезапуска приложения (чтобы не перестраивать все виджеты на лету). Содержимое самого сообщения (то, что реально уйдёт в Discord) языком интерфейса не затрагивается.

## Шрифт

Приложение подключает шрифт [Inter](https://github.com/rsms/inter) (SIL Open Font License) из `assets/fonts/Inter.ttf` — устанавливать в систему не нужно, он грузится динамически при старте. Лицензия лежит рядом в `assets/fonts/OFL.txt`.

## Установка и запуск

```bash
pip install -r requirements.txt
python main.py
```

Требуется Python 3.10+.

## Сборка в .exe

```bash
pip install pyinstaller
pyinstaller --name "DiscordWebhookSender" --windowed --onefile ^
  --add-data "assets/fonts/Inter.ttf;assets/fonts" ^
  --add-data "assets/fonts/OFL.txt;assets/fonts" ^
  main.py
```

Готовый файл появится в `dist/DiscordWebhookSender.exe` — один портативный exe, шрифт вшит внутрь. Папка `data/` с вебхуками, историей и шаблонами создастся рядом с exe при первом запуске.

## Структура проекта

```
main.py                  точка входа
app/
  config.py               константы, лимиты Discord API, пути
  models.py                Embed, EmbedField, WebhookProfile, MessageState, HistoryEntry
  storage.py                локальное хранение (JSON) профилей/истории/шаблонов
  discord_api.py             клиент Discord Webhook API + фоновый воркер на QThread
  image_loader.py             асинхронная подгрузка и обрезка (круг/скругление) картинок для превью
  utils.py                     markdown → rich text, валидация, форматирование
  theme.py                      Material Design 3 палитра и QSS
  i18n.py                        строки интерфейса на ru/en/uk
  main_window.py                 сборка интерфейса
  widgets/
    sidebar.py                    список вебхуков
    embed_editor.py                 редактор одного embed
    field_editor.py                  редактор одного поля embed
    color_picker.py                   выбор цвета полосы embed
    preview.py                         живой предпросмотр сообщения
    dialogs.py                          диалоги (вебхук, шаблоны, история)
    toast.py                              всплывающие уведомления
```

## Важно про безопасность

Ссылка на вебхук — это секрет: любой, у кого она есть, может слать сообщения от имени вашего бота. Файл `data/profiles.json`, где хранятся ссылки, не должен покидать ваш компьютер и намеренно исключён из git через `.gitignore`.
